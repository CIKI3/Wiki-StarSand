⚔️ KingdomsX 玩家完全教程 Wiki

KingdomsX 是一个"王国玩法"插件（类似 Factions/阵营）：玩家组建王国、圈占领地、建造炮塔和建筑防守基地，并通过入侵战争抢夺别人的土地和资源。

📖 本教程基于 KingdomsX 官方 Wiki（wiki.kingdomsx.com）整理翻译，内容对应插件默认配置。你所在的服务器可能自定义了规则（如价格、护盾时长、是否开启掠夺战等），一切以服务器内实际设置和公告为准。遇到问题先看【常见问题】，再用 /k help 查看服务器开放的指令。

🚀五分钟上手（新手必读）

新手路径（按顺序做）：

  1. 加入或创建一个王国
    • 加入别人：让有权限的成员邀请你，或使用 /k requestJoin <王国名> 主动申请，或向对方索取邀请码。
    • 自己创建：/k create <名字>（通常需要一笔金钱，且名字需符合服务器命名规则）。
    💡新手推荐先加入一个成熟的王国，学习玩法后再自立门户。
  2. 圈地
    • 输入 /k map 打开互动地图，直接在聊天栏点击地图上的区块即可圈地；
    • 或站在想圈的地块上输入 /k claim。
    • 领地能保护箱子、允许放置炮塔和建筑。
  3. 放置中枢（Nexus）
    • 使用 /k nexus 放置王国中枢。中枢是王国的"心脏"：升级、护盾、商店、税收、成员管理都在这里操作。
    ⚠️别人挖你的中枢会偷走王国资源点，所以一定要把它藏好、护好！
  4. 赚取资源点（RP）
    • 打开中枢里的资源点转换器（或用 /k rp converter），把多余物品放进去换 RP。
    • 普通物品每 5 个换 1 RP；钻石、绿宝石、金锭、铁锭等特殊物品单个就有更高价值（用 /k tradable 查看列表）。
    ⚠️放完物品必须点 Apply（应用） 才会转换！关闭界面或点返回只会把物品退回。
  5. 了解保护机制
    • 新王国通常自带几天免费护盾，且前几天免缴服务器税——抓紧时间发展！
    • 被入侵时，全王国成员可用 /k teleport 传送到战场支援。

🧩核心概念

王国（Kingdom）

一群共享领地和资源的玩家组成的团体。每个王国拥有独立的：资源点、银行、升级等级、职位体系、关系属性和领地。王国可以创建或加入国家。长期缴不起服务器税的王国会被解散。

领地（Land / Claim）

一个区块（Chunk，16×16 格）= 一块领地。圈占后可保护箱子、放置炮塔与建筑。

领地上限（默认规则）的构成：

  • 每名成员提供 5 格领地；
  • 加入国家后，国家内每个王国再提供 5 格；
  • "最大领地"杂项升级可增加上限；
  • 管理员可用指令额外赠送。

想要别人的领地？只能通过入侵战争抢夺。

资源点（Resource Points / RP）

王国的主要货币（属于王国而不是个人！），用于购买炮塔、建筑、护盾、弹药和升级。详见资源点章节。

国力（Might）

王国/国家的排行榜（/k top）依据"国力"计算，默认主要由资源点数量和成员数量决定。每次收税时，国力前 10 的王国和国家会获得金钱和 RP 奖励。

力量（Power，可选玩法）

部分服务器会开启类似老版 Factions 的"力量"系统：成员在线自动积累力量、死亡掉力量，王国可圈地数量受总力量限制；力量不足时你的领地可能被直接越圈（overclaim）。是否开启取决于服务器，默认关闭。

👑创建与管理你的王国

创建

/k create <王国名>
  • 通常消耗金钱（Vault 经济）；
  • 创建成功后，脚下领地会自动圈占，并把王国之家（home）设在你所在位置；
  • 创建时可选择和平主义或好战（非和平主义）路线（之后可在中枢里更改）。

王国信息与门面

指令作用
/k show [名字]查看王国/玩家详情
/k rename <新名>重命名王国（需权限，通常收费）
/k lore <描述/remove>设置王国简介，跨领地时以大标题显示在别人屏幕上
/k tag <标签/remove>设置王国简称（聊天栏等处显示的小标签）
/k top查看国力排行榜

成员管理

指令作用
/k requestJoin <王国>申请加入某王国
/k joinRequests查看/处理入国申请（需 INVITE 权限）
/k inviteCodes制作/管理邀请码（凭码即可入国）
/k promote <玩家>晋升成员职位
/k demote <玩家>降职成员
/k kick <玩家>踢出成员
/k king <玩家>转让王位（全服公告）
/k disband解散王国（仅国王可用，领地和成员全部失去，慎用！）
/k broadcast <消息>向全体成员广播（带音效）
/k merge <王国>请求把你的王国并入对方（成员、领地、RP、银行全部转移；升级等级只在己方更高时转移）

职位（Ranks）

职位在游戏内由国王配置，每个职位有：

  • 节点（Node）：职位唯一标识；
  • 优先级（Priority）：国王为 0（最高），成员最低；
  • 权限节点：如 CLAIM（圈地）、INVADE（入侵）、SURRENDER（投降）、WITHDRAW（取款）、KICK、SET_HOME、TAX_EXEMPT（免税）等。

职位权限还会与关系属性配合：例如到盟友领地放方块，先看两国关系是否允许，再看你的职位是否允许。

选举（Elections，可选功能）

王国可以开启民主选举，每周一次：

  • /k elections statement <宣言> —— 报名参选国王；
  • /k elections vote —— 打开投票界面投票。
  • 选举持续 24 小时，期间冻结成员进出；只有投票总人数超过王国成员 50%，结果才生效。

私人营地（Camps，实验性功能）

部分服务器允许玩家在无人认领的领地放置营火，快速创建一个"单人营地"型王国（名字自动为 PR-<玩家名>），适合自用防御而不打算外交的玩家。

🧠中枢（Nexus）：王国的大脑

中枢是王国最重要的"虚拟建筑"：

  • 用 /k nexus 放置（需要 NEXUS 权限）；可放置多个，不占用物品、破坏不掉落；
  • 领地被入侵或放弃时中枢自动消失；
  • 用 /k nexus open 可远程打开中枢界面（需权限）。

中枢能做的事（GUI 菜单）

  • 🛡️ 购买/续费护盾、切换和平主义模式；
  • ⚙️ 调整关系属性（对盟友/停战国开放哪些权限）；
  • 💰 设置税收公式；
  • ⬆️ 购买升级（杂项升级如防爆、领地上限；冠军升级等）——部分服务器的等级系统会锁定高级内容，需先提升王国等级；
  • 🛒 炮塔/建筑商店；
  • 👥 成员与职位管理；
  • 📬 王国邮箱。
⚠️保护中枢！非盟友王国的玩家挖掘你的中枢会偷走王国资源点，每次挖掘都有损失。把中枢埋进基地最深处，配合能量核心（Powercell）防护。

💎资源点（RP）：王国的血液

获取方式

方式说明
资源点转换器中枢内打开或 /k rp converter。普通物品 5 个 = 1 RP；特殊物品（钻石/绿宝石/金/铁等，见 /k tradable）单个价值更高。必须点 Apply 才转换，关闭界面/Back 会退回物品
提取器（Extractor）放置后自动产 RP（有储量上限，需要燃料，没燃料就停工）
入侵掠夺赢下入侵可抢走对方 RP（入侵中枢区块还有额外金钱+RP 战利品）
挖别人中枢每挖一次偷一点对方 RP
/k sell把手里的炮塔/建筑卖回给系统换 RP
/k donate <王国> <数量>向别国捐赠 RP（需 WITHDRAW 权限）
排行奖励收税时国力前 10 的王国/国家获得金钱+RP
前哨站建筑类似全球股票市场，买卖价格受全服影响（高级玩法）

与金钱互转

/k rp deposit <数量>       # 把金钱转换成王国 RP
/k rp withdraw <数量>      # 把王国 RP 转换成金钱
⚠️RP 属于王国，个人无法持有。玩家税不能用 RP 缴纳。

王国仓库

/k vault 直接打开王国共享箱子（需权限）。

🏰建筑（Structures）

建筑是放在领地里的功能性方块。购买：中枢商店；放置后右键打开操作界面。破坏后重新放置即可继续使用（中枢除外）。

建筑功能
中枢 Nexus王国核心。被入侵后自动消失，不会掉落
能量核心 Powercell保护以自身为中心 3×3 领地：敌人必须先攻下 Powercell 所在领地，才能入侵周围 8 格。围绕中枢布置是防入侵的核心策略
提取器 Extractor随时间自动生产 RP（有储量上限），需要燃料，右键 GUI 查看/补充燃料
前哨站 Outpost（建筑）用 RP 购买各种物品 + 远程访问中枢，放在前线很方便
传送垫 Warp Pad在王国各建筑间传送。往垫子上扔煤炭充能（1 煤 = 30 燃料）；传送费用 = 两点间距离的一半（跨世界固定 300 燃料）。每个传送垫可命名，显示在全息图和传送菜单里
调节器 Regulator管理所在领地的规则（只管自己这一格！），见下表
攻城炮 Siege Cannon攻城重武器，见下文
💡同一格领地可以放多个建筑（但中枢和国家中枢不能共存于同一格）。

调节器（Regulator）规则

对其所在领地生效：

  • 禁止怪物生成（仅自然生成，不影响王国的守卫/士兵/冠军）；
  • 禁止动物生成；
  • 关闭炮塔（临时让所有人安全进入该格）；
  • 允许爆炸（默认因防爆升级禁爆，可在此单独放开；也可在中枢直接关闭整个王国的防爆升级）；
  • 自动补弹：炮塔弹药打空且王国付得起钱时自动充满；
  • Attributes（属性）/ Interactions（交互）：授权领地外的特定玩家管理/使用这格里的东西（无视关系属性）。

攻城炮（Siege Cannon）

用途：轰击敌方王国领地，削减护盾；护盾归零后可摧毁炮塔和建筑（无视防爆升级）。

  • 在 GUI 里装填特殊弹药 → 点 GUI 坐上炮台 → 调整炮管 → 左键开火（坐着时右键任意处可随时打开 GUI）；
  • 射击冷却 10–20 秒（依炮等级）；
  • 命中任意王国领地都会削减其护盾，并报告命中情况；
  • 不能摧毁能量核心和中枢；对友方领地同样有效（小心轰到自己家！）；护盾未破时打不坏建筑。

🗼炮塔（Turrets）

炮塔是自动防守的"哨戒方块"，也会打怪。

要点

  • 只能放在栅栏/墙类方块上；
  • 需要弹药才能开火：右键炮塔打开 GUI 购买（也有满弹一键购买）；
  • 可右键升级：提升射程、伤害、载弹量等（GUI 里可见下一级预览）；
  • 是否射击取决于两国关系属性（如 TURRET_CEASEFIRE）——盟友领地不会被你的炮塔打；
  • 和平主义王国的炮塔不会射击玩家；对和平主义王国的玩家也不射击；
  • 治疗/灵能/士兵类炮塔只针对玩家；炮塔一般不攻击动物、水生生物和 NPC；
  • 炮塔数量过多可能造成卡顿，服务器通常有限制。

常见炮塔类型

类型作用
箭矢型（arrow）发射箭矢攻击敌人，最常见
火焰型（inferno）喷火/燃烧敌人
治疗型（healing）为己方和盟友回血（只在有人掉血时触发）
士兵型（soldier）在敌人靠近时刷出士兵追杀
压力雷（pressure_mine）地面陷阱类
💡炮塔不射击？→ 看文末 FAQ。服务器管理员还能自制炮塔，所以你见到花式炮塔别惊讶。

🤝关系与外交

关系类型

玩家之间没有直接关系——一切关系都是王国之间的：

关系说明
中立 Neutral默认状态，无特殊待遇（对方不属于任何王国时也是中立）
国家 Nation同一国家内的王国（未单独结盟时）
盟友 Ally结盟，访问权限最高
停战 Truce类似盟友但权限更低
敌对 Enemy宣战（默认只是"标记"，允许入侵等战争行为的前提）
/k ally <王国>      # 请求结盟
/k truce <王国>     # 请求停战
/k enemy <王国>     # 宣战
/k revoke <王国>    # 撤销与某王国的关系

关系属性（Relation Attributes）——"双向同意"机制

国王在中枢设置里，为每种关系配置属性，例如：

  • CEASEFIRE（停火）：允许对方在领地内 PvP/造成伤害与否；
  • TURRET_CEASEFIRE（炮塔停火）：炮塔不打对方；
  • BUILD（建造）/ INTERACT（交互）：允许对方建造/使用方块；
  • MANAGE_STRUCTURES（管理建筑） 等。
❗关键规则：大多数属性需要双方都开启才生效。
例：你给盟友关了停火，但对方给你开着 → 盟友依然能打你。这是为了避免一方突然改设置导致另一方被动挨打。

聊天频道

/k chat k      # 王国频道（只有成员可见）
/k chat a      # 盟友频道
/k chat n      # 国家频道
/k chat g      # 全局频道
/k chat k <消息> # 不切换频道，临时发一条
  • 支持 @名字 提醒（被@的玩家有音效和动作栏提示）；
  • 支持 ! 前缀在受限频道喊话（部分服务器开启）；
  • 支持彩色代码和十六进制颜色（需权限）。

其他相关机制

  • 下界传送门保护：目的地领地属于与你没有停火属性（含炮塔停火）的王国时，传送会被取消——无法用下界门偷袭。
  • 信标：在已圈领地里，只有拥有停火属性的玩家才受信标效果影响。
  • 喷溅药水：不得对有停火属性的玩家使用负面药水（中毒、虚弱等）。
  • /k pvp：允许你与 Normally 打不了的自己王国成员/盟友切磋。双方都开了才生效；无法绕过 WorldGuard 等其他插件的 PvP 禁止。

🌐国家（Nations）

国家 = 多个王国组成的联盟（类似"文明"）。由创建国的国王担任国家元首，该国称为首都（capital）。国家没有升级系统，其余玩法与王国高度相似。

加入国家的好处

  • 领地上限增加（国家内每国 +5 格）；
  • 成员王国被入侵时，首都的冠军会参战协防；
  • 国内任意王国被入侵，全国家收到警报；
  • 可购买国家护盾，罩住所有成员国；
  • 国家聊天频道、国家职位、国家领地圈占。

坏处/风险

  • 国家没有护盾时，任何成员国都可能被入侵（即使该王国自己开着护盾）；
  • 国家的和平主义状态会强制施加于成员国；
  • 首都冠军较弱时反而可能拖累防守。

国家区域（Nation Zones）

首都领地周围 3×3 的缓冲地带（默认半径 1），非本国成员不能圈占、入侵、建造；想深入必须先把周边整圈领地全部打下来。国家区域不会显示在 /k map 上。

/k nation top          # 国家排行榜
/k nation show <名字>   # 查看国家信息
/k chat n              # 国家频道

国家创建/邀请等指令与王国指令一致（在中枢/子指令里操作，具体以服务器为准）。

💰税收与银行

征收顺序：玩家 → 王国 → 国家 → 服务器（交给服务器的钱直接消失）。默认每 24 小时收一次。

  • 玩家税：从玩家账户收钱，交给所属王国；成员头几天免税；职位有 TAX_EXEMPT 权限的免税；
  • 王国税：国王可在中枢设置自己的收税公式，从成员处收取；王国银行的钱用于缴纳国家税和服务器税；
  • 国家税：首都管理，向成员国收取；国家付不起服务器税会被解散，王国付不起会被解散；
  • 新手保护：新王国、新成员、新国家头几天免税。

王国银行指令

/k bank deposit <金额>    # 存钱进王国银行（用于缴税）
/k bank withdraw <金额>   # 取钱（需 WITHDRAW 权限）

🛡️护盾与和平主义

和平主义（Pacifism）

一种王国状态：与所有王国强制友好——不能入侵别人，别人也不能入侵你，不能 PvP，攻城炮对它无效。国家无法和平主义。

  • 创建王国时选择，或之后在中枢设置里切换；
  • 上次入侵后的一段时间内无法切换回和平主义（防逃逸）。

护盾（Shields）

在中枢购买，倒计时内免疫入侵：

  • 新购护盾时长累加到现有护盾上；
  • 护盾可以被敌方攻城炮轰掉；
  • 新王国通常自带几天免费护盾；
  • 国家护盾可覆盖全体成员，但国家没护盾时成员各自的护盾失效（默认规则）。
💡防守思路：靠和平主义躺平会被限制很多（不能 PvP、不能被打也不能打人），更常见的是"好战 + 买护盾 + 攒 RP 维持护盾"的路线，在护盾倒计时结束前完成军事准备。

大规模战争（Mass Wars）

全服定时活动（默认每 12 小时一次），开启时全服大标题 + BossBar 计时：

  • 默认规则下，可以入侵有护盾的王国、入侵免费且不限次数；
  • 部分服务器只在全民战争期间允许入侵——具体看服务器配置；
  • 管理员可手动开始/结束。

⚔️战争与入侵（重点！）

发动入侵

/k invade      # 站在想抢的敌方领地上发动入侵
/k ransack     # 快速掠夺：只抢钱和 RP，不占领地（中枢格不可用）

入侵目的：抢箱子物资、占领建筑、抢 RP 和钱。打下中枢所在格奖励最丰厚（额外偷取该国 RP 和银行金钱）。

发动入侵可能被拒绝的原因

  • 对方有新手保护 / 护盾 / 和平主义；
  • 实力差距限制：你明显更强时反而打不了弱国（弱国可以打强国，保护平衡）；
  • 关系不满足要求（如需要先 /k enemy 宣战或用 /k challenge 下战书）；
  • 服务器限定只在全民战争期间允许入侵；
  • 你没有 INVADE 职位权限、处于创造/隐身/上帝模式；
  • 该国正被别国入侵 / 双方各有入侵数量上限 / 入侵冷却中；
  • 王国付不起入侵花费（RP/金钱）。

冠军（Champion）——入侵的核心

每个王国的守护者，默认是一只僵尸（可在中枢升级强化、更换类型，部分服务器接入 MythicMobs 自定义 Boss）：

  • 有人入侵你的领地时自动刷出，只会追击发起入侵的玩家，绝不换目标；
  • 入侵者在冠军 13 格内可看到血条和时限 BossBar；
  • 杀掉冠军 = 占领该格；多人可同时入侵同一格，谁先杀掉归谁；
  • 冠军免疫自然伤害类效果（如阳光燃烧、僵尸变溺尸），不能穿过传送门。

入侵期间的限制（双方）

  • ❌ 任何形式的传送（指令、道具、传送门等）；
  • ❌ 部分指令被禁用；
  • ❌ 部分方块交互被禁用。

入侵结束方式（任意一条）

  1. 冠军被击杀 → 入侵者获胜，领地易主；
  2. 冠军计时结束 → 防守方获胜；
  3. 入侵者死亡/下线/被踢出王国 → 防守方获胜；
  4. 任意一方 /k surrender 投降（防守方投降 = 送地；进攻方投降 = 退兵，都有惩罚）；
  5. 领地被放弃 / 任一方王国解散。

防守方怎么做

  • 全体成员 /k teleport 传送到入侵现场回防（传到入侵者进来的位置，避免陷阱）；
  • 让冠军拖住入侵者，靠炮塔、守卫、人海围杀；
  • 实在打不过：有 SURRENDER 权限的成员 /k surrender 及时止损；
  • 平时防御布置：中枢格放 Powercell 环形布防；升级冠军；修好炮塔弹药房；别只堆黑曜石墙——高空飞行机器（粘液块飞机）是它的克星，注意天花板和地下洞穴。

掠夺战（Plunders，可选入侵模式）

部分服务器把冠军模式换成"击杀计分"的团队战：

  • 双方在领地内互杀，先杀满对方死亡上限的一方获胜；
  • 任何死法都计入对方比分（包括摔死、怪杀），盟友可以参战；
  • 若限时内防守方一直被压在圈外（占领进度机制，类似 KoTH），进攻方直接获胜；防守方撑到时间结束则获胜；
  • 盟友不参与占领进度的计算。

挑战（/k challenge，可选机制）

/k challenge <王国>

开启此机制的服务器，入侵前必须先"下战书"：选择准备时间，倒计时结束后你有 6 小时窗口可以入侵该国任意领地；过期需重新下战书。

🛡️王国守卫与士兵

  • 王国守卫（Guards）：没有停火属性的玩家踏入敌方领地时刷出的卫兵（中枢格的更强）。只追它锁定的那名玩家，直到：杀死目标 / 目标下线 / 目标传送（珍珠和紫颂果除外）/ 超时。
  • 同一王国的守卫不会重复刷：只要还有一只在追你，就不会来第二只（看不到不代表没有！）。
  • 士兵（Soldiers）：由士兵炮塔刷出的援军，机制同上。
💡被守卫追时用末影珍珠或紫颂果位移不算传送，守卫不会立刻消失——但它们超时后也会自己离开。

🔒保护牌：锁住你的箱子

王国专属的箱子保护（类似 Lockette）：

上锁方法（任选其一）

  1. 对着箱子贴一张告示牌，第一行写：[protect] / [protected] / [private] / private；
  2. 手持告示牌潜行 + 左键点击箱子（最快，创造模式也有效）。

上锁成功后告示牌会自动变化。只有你能开箱/破坏箱子和牌子；合成双箱时另一半自动受保护。

开放权限写法

  • [everyone] —— 全国成员可用（不可破坏）；
  • [everyone*] —— 所有人都可用（不可破坏）。

高级设置：右键牌子可编辑保护类型、添加允许/禁止的玩家和王国名单（优先级高于保护类型）。

漏斗/管道规则：受保护容器与未保护容器之间不能自动转运物品；两个保护物属同一玩家、或目标容器的主人有权访问源容器时才可以。

📬王国邮件

王国官方信箱（在中枢里），用于王国之间的正式沟通——属于王国而非个人：

  • 查看：需要 VIEW_MAILS 职位权限；
  • 写信：需要 MANAGE_MAILS 权限。点击信箱顶部的书本图标获得专用信纸（书）；
  • 信的内容 = 书里的文字（支持颜色，不支持占位符）；
  • 潜行 + 右键书本：设置主题、抄送（CC）收件人、预览效果；
  • 写完后回到信箱，把书丢进空槽位即发送。

🕊️和平条约与附庸（插件功能）

安装了 Peace Treaties 插件的服务器，战后可以用条约正式结束战争状态：

  • 向敌对王国发送提案：/k neutral <王国>；
  • 对方通过邮件收到条约，可用 /k pt accept 接受 / /k pt reject 拒绝；/k pt review 查看所有往来条约。

条约条款（消耗战争点数来设定）

条款效果
索取资源点对方支付指定 RP
战争赔款对方从王国银行支付指定金钱
割地（保留领地）从入侵所得领地里勾选保留哪些
退出/解散国家强制对方离开国家（或解散其国家）
附庸化长期限制（见下）
  • 战争点数（War Points）来源：击杀敌人、赢下入侵、破坏敌方炮塔/建筑。点数按敌国分开累计——对 A 国攒的点只能用在 A 国身上；
  • 无任何条款的条约叫白色和平（white peace）；
  • 条约生效后全服公告，且两国在一定时间内不能再互相宣战（防止强国反复刷弱国）。

附庸（Vassalization）

宗主国可长期控制附庸国：

  • 抽成附庸的银行收入（Scutage）；
  • 强制继承宗主的外交关系、禁止自主改关系；
  • 限制领地总数、炮塔和建筑数量；
  • 宗主可修改附庸的关系属性、开关其杂项升级；
  • 附庸只能有一个宗主；成员数/领地数超限的王国无法被附庸；
  • 解除方式：由第三国击败宗主并强制其签下释放附庸的条约。

🚩前哨战 Outposts（插件活动）

服务器安装 Outposts 插件后的 KoTH（王中之王）式全服活动：

  • 世界中会设立若干前哨区域（WorldGuard 区域）；
  • 参战需王国支付少量金钱+RP 报名，有成员人数上下限；
  • /k outposts join <区域> 报名，/k outposts tp 传送进场；
  • 活动开始后，累计站在区域内时间最多的王国获胜，获得 RP、金钱和物品奖励；
  • 场内可能刷新特殊怪物，击杀有额外奖励；
  • 结束后失败方被传送回出生点，物品奖励掉落在指定位置，先到先得。
⚠️注意区分：Outpost 建筑（领地内买物品、远程开中枢的小建筑）和 Outpost 前哨战活动是两回事。

❓常见问题 FAQ

炮塔不射击？
依次检查：服务器刚启动后炮塔需要约 1 分钟加载；有没有弹药（右键炮塔买弹）；你们与炮塔所属王国是否有炮塔停火属性（治疗塔则相反，只认友军）；该领地的调节器是否关闭了炮塔；你是否处于创造/隐身/上帝模式（炮塔不打这种人）；双方是否有一方是和平主义；部分炮塔（治疗/灵能/士兵）只锁定玩家，不打动物和 NPC；炮塔的射线检测在贴脸等个别站位下可能失灵。
提取器不产资源点？
检查燃料，没燃料就停工。右键提取器打开 GUI 加燃料。
踏进敌方领地提示守卫来了却看不到怪？
守卫只追它锁定的目标且全王国同一时间只刷一只——可能在很远的地方追你；若提示音效齐全却始终没怪，多半是插件冲突，报告给服务器管理员。
为什么不能打自己王国的成员/盟友？
关系属性默认关闭友军 PvP（防误伤）。想切磋：双方都输入 /k pvp。仍不行则是 WorldGuard 等其他插件禁止了该区域 PvP。
被入侵了怎么办？
1️⃣ 全员 /k teleport 回防；2️⃣ 保护并协助冠军（它只咬入侵者一个人，拖住即可）；3️⃣ 利用地形+炮塔+守卫消耗对方；4️⃣ 守不住就让有权限的人 /k surrender 止损。平时：中枢格用 Powercell 布防、升级冠军、保持炮塔弹药充足。
/k invade 用不了？
对照"发动入侵可能被拒绝的原因"清单：护盾/和平主义/新手保护、实力差距、没宣战或没下战书、只在全民战争开放、没有 INVADE 权限、冷却中、RP 或金钱不足。
下界传送门传不过去？
目的地领地属于与你没有停火属性的王国时，传送会被插件取消（防偷袭机制）。绕路或先改善关系。
领地里信标没用？
信标只对拥有停火属性的玩家生效。让访客与你结盟/停战，或把信标挪到公共区。
入侵中枢格有什么额外好处？
除了占领土地，还会额外从该国偷取资源点和银行金钱——所以大家最爱打中枢，也最该保护中枢。
被抓进附庸/收到条约怎么办？
条约邮件在中枢信箱里，/k pt accept / /k pt reject 自由选择；接受附庸会长期受限（强制外交、抽成、限建），想翻身需要第三国帮你打赢宗主。
怎么查看我的王国还有多少领地上限？
/k show 查看王国信息；上限 = 成员数 × 5 + 国家加成 + 升级加成（默认规则）。
聊天里的 @某人 是什么？
游戏内提醒功能：被 @ 的玩家会有音效和屏幕提示。可用 /k chat 切换频道；! 开头可在部分受限频道发言。
